# AI-Engineer-Journey
In this Repo i am learning to the AI engineering concepts using 7 layers.

**7 layers**:

1. **LLM fundamentals**
    - Tokens and tokenization
    - Context windows
    - Transformers — high-level understanding first
    - Attention
    - Parameters and inference
    - Temperature/top-p
    - Model limitations and hallucinations
    - Structured outputs / JSON
    - Streaming
2. **Prompt engineering**
    - System vs user instructions
    - Few-shot prompting
    - Structured prompting
    - Output constraints
    - Prompt decomposition
    - Reasoning/task planning patterns
    - Prompt injection and instruction conflicts
    - Prompt evaluation
3. **Embeddings + vector search**
    - What embeddings represent
    - Similarity/search
    - Chunking
    - Metadata
    - Vector databases
    - Hybrid search
    - Reranking
    - When vector search is actually unnecessary
4. **RAG**
    - Document ingestion
    - Chunking strategies
    - Embedding pipelines
    - Retrieval
    - Context construction
    - Generation
    - Citation/grounding
    - RAG evaluation
    - Advanced RAG
5. **AI agents + tool calling**
    - Function/tool calling
    - Agent loops
    - Tool selection
    - State and memory
    - Multi-step tasks
    - Human approval
    - MCP
    - Agent security
    - Failure handling
6. **Production GenAI**
    - API integration
    - Authentication/authorization
    - Cost management
    - Caching
    - Rate limits
    - Observability
    - Logging/tracing
    - Evaluation
    - Guardrails
    - Latency
    - Model selection
7. **AI-powered products**
    - Build real applications rather than isolated tutorials.
    - Combine your existing React/React Native/Node/Nest/Postgres skills with AI.
